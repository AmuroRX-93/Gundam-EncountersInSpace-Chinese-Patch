## 安装

1. 准备匹配下方 SHA256 的日版原始 ISO；不能使用美版、其他日版修订、旧汉化、CHD 或压缩包作为输入。
2. 完整解压补丁。Windows x64 双击 `Windows_Install.cmd`；Apple Silicon / Intel Mac 双击 `macOS_安装.command`。包内已附各自的 Python，不必另装或联网。
3. 将原版 ISO 拖入窗口并回车，等待合成及完整校验。输出 `GundamEIS_CHS_0.1.0.iso`，不会修改原盘或覆盖已有输出。
4. 用新 ISO 正常启动游戏，再读取记忆卡内存档。不要用旧即时存档判断新程序或字库是否生效。

解压后的补丁及运行环境约 3.31 GB，另需至少 4.8 GB 输出空间；下载压缩包另占空间。保留原盘以便恢复。输出超过 4 GiB，不能直接存入 FAT32。

已有本地测试版也从原盘重新合成，不在旧测试镜像上叠加。本安装器不修改记忆卡、不更改模拟器配置、不启动游戏。恢复时重新选择保留的原版或旧版镜像。

- 日版菜单、说明与部分 UI 中文化，预录影片中文字幕及影片封包修复。
