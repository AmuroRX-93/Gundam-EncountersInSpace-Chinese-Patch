# Encounter in Space ALLPLATFORM 1.0.1

《机动战士高达 相逢在宇宙》PS2 日版中文修正版，原盘 SLPS-25062 / 修订 1.03。

## 修复

普通结算和阿尔比昂结算中的“得分”“特别奖励”改为整词贴图后，仍使用英文首字母的14×18绘制尺寸，导致中文被压成竖线。1.0.1修正全部4个标签变体、16个动画关键帧：宽度216、高度22，隐藏帧高度0保持。

与1.0正式版相比，整盘仅改变24个字节。保留4703条语音字幕、字库、影片、原日语音频和游戏逻辑，不带存档、模拟器、BIOS或本地测试金手指。

## 下载

[下载1.0.1累计差分](https://github.com/AmuroRX-93/Gundam-EncountersInSpace-Chinese-Patch/releases/tag/v1.0.1)。下载所有同名前缀的 `.7z.001` 至 `.7z.006` 到同一目录，从 `.001` 解压；`SHA256SUMS.txt` 是分卷校验值。GitHub的 Source code 不含完整补丁载荷。

累计差分直接从匹配的日版1.03原盘生成新版ISO，不要求先装1.0。Windows/macOS/Linux提供x64与ARM64六套内置Python、安装入口和许可证；安卓可使用标准XDelta或导入电脑生成的ISO；PS2使用同一生成镜像按加载器要求部署。

已有精确1.0 ISO也可以运行 [tools/fix_result_layout.py](tools/fix_result_layout.py) 生成一个新1.0.1 ISO。该小更新器只依赖Python标准库，输入不覆盖，输出校验通过才完成。

正常重新启动游戏，加载记忆卡存档；旧即时状态可能保留旧UI尺寸。ISO超过4GiB，不能直接作为单文件放入FAT32，7z分卷不是OPL游戏分片。

## 验证与限制

全量对照193份DRM、61144对象、252047动画关键帧；619个汉化文字消费者中的本类遗漏已修，另26个手工区域通过资源头/静态参数比较排除同类回归。四标签关键帧无共享修改，位置、深度、时间、颜色、隐藏状态与其他字节保持。

包内Apple Silicon Python和标准XDelta均从原盘完整重建到同一目标；安装器保护测试、包清单/来源/六架构文件检查通过。其他电脑架构、安卓和PS2实机仅提供入口/部署说明，未在相应设备实测。本次未启动模拟器，实际画面仍需玩家验证；离线几何重建不能冒充游戏实录。
