# 1.0.1 — 结算标签尺寸修复

当普通结算或阿尔比昂结算页显示“得分”和“特别奖励”时，整词贴图仍被按英文首字母尺寸绘制，文字被压成竖线。修复全部4个标签变体的16个动画关键帧：宽度14→216，高度18→22；8个隐藏帧保持高度0。

全盘只改变24个字节。1.0的4703条语音字幕、字库、影片、原音及游戏逻辑保持不变。

193份DRM、61144对象、252047关键帧已对照审计；619个汉化文字消费者中只有这4处存在本类新旧尺寸不匹配。另26处非直接DRM匹配区域已核对资源头及原生静态参数。

离线几何检查、唯一关键帧归属及全盘修改白名单通过。画面示意为资源与动画重建，不是模拟器实录；全场景动态验收仍待玩家测试。
