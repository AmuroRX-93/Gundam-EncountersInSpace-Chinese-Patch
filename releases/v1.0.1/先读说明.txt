【这是累计差分包】
只需日版 SLPS-25062、光盘修订 1.03 的原始 ISO，一次生成 1.0.1，无须安装旧汉化。
PC、安卓手机、PS2 实机共用同一份中文 ISO。全平台是交付范围，不表示每个设备均经过运行测试。

GitHub 自动生成的 Source code 不含补丁数据、运行环境，不能作为安装包。

【PC：Windows / macOS / Linux】
1. 完整解压本包；不要在压缩软件预览窗口中运行。
2. Windows 双击 Windows_安装.cmd；macOS 双击 macOS_安装.command；Linux 在终端执行 sh run.sh。
3. 输入 1，回车，将日文原版 ISO 拖入窗口并回车。输出默认在原版 ISO 同一文件夹，名为 Encounter_in_Space_ALLPLATFORM_1.0.1.iso。
4. 等待“4/4 安装成功”及完整校验通过，窗口会显示生成文件的绝对路径。
5. 将新 ISO 添加到 PS2 模拟器游戏列表，正常启动后读取记忆卡存档。
包内提供 Windows x64/ARM64、macOS Intel/Apple Silicon、Linux x64/ARM64 六套便携 Python。无需自行安装 Python、pip 或联网获取依赖。
内置工具只生成与校验 ISO，不会自动启动模拟器、修改手柄、安装游戏到某个模拟器内部目录。
Linux 运行环境为 glibc 构建；不支持 Alpine/musl、32 位系统。Windows 使用 Python 3.13 嵌入版，面向 Windows 10/11。

【安卓手机：两条路径】
A. 已有合成 ISO：把中文 ISO 复制到手机可访问的游戏目录，在 PS2 模拟器里添加该目录或选中 ISO。
B. 只有原盘和本差分包：解压本包，在支持 XDelta 与大文件的修补工具（例如 UniPatcher）中选择：
   原始文件＝匹配下方 SHA256 的日版 1.03 原盘 ISO；
   补丁文件＝standard-xdelta/Encounter_in_Space_ALLPLATFORM_1.0.1.xdelta；
   输出文件＝新文件 Encounter_in_Space_ALLPLATFORM_1.0.1.iso。
   完成后核对输出大小和 SHA256，再导入模拟器。不要选择 update.bin，它只供电脑内置安装器使用。
UniPatcher 官方入口：https://github.com/btimofeev/UniPatcher
本包的标准 XDelta 已在电脑完整重建校验；尚未在安卓设备验证这份 4.64 GB 镜像的修补和运行。若手机工具不支持此大文件，请在电脑合成后传入，或使用同版整合包。

【PS2 实机】
先在电脑/手机合成或解压中文 ISO，再按自己的 OPL 与存储方式部署。
USB/MX4SIO：只有确认当前 OPL 和介质支持大文件/exFAT 时，才将完整 ISO 放入设备的 DVD 目录。
SMB：将 ISO 放入配置好的共享游戏目录中的 DVD 目录。
内部硬盘：使用自己的 OPL/硬盘安装流程导入，不应简单复制到任意硬盘目录。
本 ISO 大于 4 GiB，不能作为单文件写进 FAT32。7z 分卷不是 OPL 游戏分片；需要 FAT32 专用拆分时，使用符合当前加载器要求的游戏安装工具处理合成后的 ISO。
OPL 官方项目：https://github.com/ps2homebrew/Open-PS2-Loader
本版未做 PS2 真机验收，不改变记忆卡或 VMC。不为此任务格式化任何磁盘。
